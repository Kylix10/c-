# 《万里遐征》——以《徐霞客游记》为背景的像素游戏
## 项目简介
本项目以《徐霞客游记》为游戏背景，打造古风RPG像素风小游戏。玩家通过走剧情、完成地图闯关收集山川图鉴与地域特色物品，辅之以书籍原文描述，将文学作品具象化重现，呈现中国山川之美，展现传统文学之魅力与价值。
适量添加趣味元素具象化展现《徐霞客游记》内容的同时，保留文学本质，激发玩家对中国古典文学的兴趣。
## 游戏背景
玩家身份：
玩家意外穿越到《徐霞客游记》著成前，跟随徐霞客的脚步跋山涉水，用随身携带来的相机记录书中山川之姿，收集特色风物，体验万里遐征。
徐霞客的游历：
选取五个典型地点：黄山、天台山、万峰林、悬空寺、少林寺
